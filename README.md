# 👥 Employee Project Analysis

**Tools:** Python • Pandas • NumPy

## 📌 Situation
Employee, project and seniority-level data sat in three separate CSV files, with missing project costs and no consolidated view of project outcomes.

## 🎯 Task
Merge the datasets, clean the data, and apply business rules for bonuses and designation levels.

## 🛠️ Action
- Merged 3 CSV sources (employee, project, seniority level) using Pandas
- Imputed missing project costs with a running average using a custom loop
- Split employee names into first name and last name
- Applied business logic:
  - 5% performance bonus on finished projects
  - Designation level -1 for employees on failed projects
  - Designation level +1 for employees aged over 29

## 📈 Results
- **50%** of projects finished
- **21%** failed
- **29%** ongoing
